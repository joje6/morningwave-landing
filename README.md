# 모닝웨이브

한국어 가상 스페셜티 커피 브랜드 랜딩 페이지입니다. 의존성 설치나 외부 이미지·폰트·API 없이 동작하는 정적 사이트입니다.

## 요구 사항

- Node.js 18 이상

## 개발 및 빌드

```sh
npm run build
```

정적 사이트가 `dist/`에 생성됩니다. 생성된 디렉터리를 정적 호스팅 서비스에 게시하면 됩니다. 로컬에서 미리 보려면 프로젝트 루트에서 `npx serve dist`를 실행하세요.

## 구성

- `public/` — HTML, CSS, JavaScript 및 SVG 파비콘
- `scripts/build.mjs` — `public/`을 `dist/`로 복사하는 의존성 없는 빌드

모바일 메뉴와 구독 폼 피드백은 클라이언트에서만 동작합니다. 폼은 데모이며 구독 정보를 저장하거나 전송하지 않습니다.
